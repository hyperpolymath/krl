= KRL — Quick Start for Platform Maintainers
:toc:
:toclevels: 2

== Overview

This guide covers packaging, deploying, and maintaining KRL for distribution.

== Runtime Dependencies

- Zig 0.16.0+ (FFI build)
- Julia 1.12+ (conformance tests, requires QuandleDB checkout)
- Podman (container builds)
- Just (task runner)

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/krl.git
cd krl
just build-release
----

Output: `src/interface/ffi/zig-out/lib/libkrl.a`

== Packaging

=== Guix

[source,bash]
----
guix build -f build/guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (Stapeln)

[source,bash]
----
podman build -t krl:latest -f Containerfile .
# Or via stapeln:
just container-build
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables (if any)

| `$PREFIX/lib/`
| libkrl.a (FFI library)

| `$PREFIX/share/doc/krl/`
| Documentation

| `$PREFIX/share/man/man1/`
| Man pages (generated via just man)
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/krl/config.toml`

Fallback: `$HOME/.config/krl/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just validate-rsr      # RSR compliance
just verify-template   # Template instantiation
----

== Updating

[source,bash]
----
git pull
just build-release
----

== Security Notes

* License: MPL-2.0
* All dependencies SHA-pinned where applicable
* Container base images digest-pinned (@sha256:)
* OpenSSF Scorecard: see badge in README

== Multi-Instance Deployment

For deploying multiple instances:

[source,bash]
----
just install --prefix=/opt/krl-instance1
just install --prefix=/opt/krl-instance2
----

Each instance has isolated config, data, and logs.

== Reporting Issues

* Upstream: https://github.com/hyperpolymath/krl/issues
* With diagnostic: `just help-me` (pre-fills context)
