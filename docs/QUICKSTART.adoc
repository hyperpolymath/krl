= Quickstart — KRL
:toc: preamble

Get up and running in 60 seconds.

== Prerequisites

* Git 2.40+
* just (command runner)
* Zig 0.16.0+ (FFI)
* Julia 1.12+ (conformance tests, optional)

== Clone and Test

[source,bash]
----
git clone https://github.com/hyperpolymath/krl.git
cd krl
bash tests/smoke/grammar_smoke.sh
cd src/interface/ffi && zig build test
----
